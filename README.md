# Dead Zero plug-ins

Install and update everything with **DZ Central** (Mac, Apple Silicon or Intel).

1. Download the DZ Central zip from the table below and double-click it.
2. Move **DZ Central** to Applications and open it.
3. DZ Central is not notarized by Apple yet, so the first time macOS refuses to open it. Go to
   System Settings > Privacy & Security, scroll down, click **Open Anyway** next to DZ Central and confirm.

After that, open DZ Central any time: it shows every plug-in, installs them and keeps them (and itself)
up to date. Quit Logic before updating, then reopen it. Plug-ins appear in Logic under **Dead Zero**.
